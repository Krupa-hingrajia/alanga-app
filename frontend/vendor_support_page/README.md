# ALANGA Vendor Support Web Page

Official Vendor Support page for ALANGA Marketplace Vendor App.

---

## 🚀 How to Publish to Vercel (2 Simple Methods)

### Method 1: Using Vercel CLI (Super Fast - 30 seconds)
1. Open terminal and navigate to this folder:
   ```bash
   cd "frontend/vendor_support_page"
   ```
2. Run the deployment command:
   ```bash
   npx vercel --prod
   ```
3. Follow the quick prompts in terminal (Login if prompted, accept defaults with Enter).
4. Your page will be live on a Vercel URL instantly (e.g., `https://alanga-vendor-support.vercel.app`).

---

### Method 2: Via Vercel Web Dashboard (Drag & Drop or GitHub)
1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **"Add New..."** > **"Project"**.
3. Import your GitHub repository or upload this `vendor_support_page` directory.
4. Click **Deploy**.
